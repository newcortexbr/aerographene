# cada space é uma janela própria

No Chromium, uma janela pertence a um único perfil. Fazer uma janela hospedar abas de vários perfis, como o Arc, é um patch profundo e frágil a cada rebase. Por isso cada space é uma janela: trocar de space troca a janela no mesmo lugar e tamanho, parecendo uma só. Há opção de abrir um space à parte em outra janela.
