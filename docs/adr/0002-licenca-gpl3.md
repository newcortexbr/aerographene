# licença GPL-3.0

O aerographene é GPL-3.0. O usuário queria a licença mais aberta possível com menos dor de cabeça. Uma licença permissiva (BSD-3/MIT) obrigaria a reescrever do zero todo patch inspirado no Helium, cuja parte própria é GPL-3.0. Com GPL-3.0, patches do Helium podem ser copiados com atribuição, e as partes BSD do Chromium e do ungoogled são compatíveis.
