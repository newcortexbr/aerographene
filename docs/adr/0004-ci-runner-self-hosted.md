# build em runner self-hosted da org newcortexbr, sem execução de terceiros

O repositório é `newcortexbr/aerographene` (privado por ora; transferido de dashwr em 05/10/2026). O build roda no runner self-hosted "intense" da org `newcortexbr`, no Cezanne (R5 5600G, ~15 GB de RAM). Até 09/10/2026 o host era WSL2 Ubuntu 24.04; desde 10/10/2026 é Ubuntu 24.04 bare metal (kernel XanMod x64v3, zram + swap), com os mesmos três runners, o mesmo cache em `~/aerographene-build` e a mesma regra de disparo. A troca de host não muda esta decisão. O repositório fica na org. Como é open-source e o runner executa código na máquina do usuário, só o dono dispara builds: os workflows rodam em `push`/`workflow_dispatch` do dono, nunca em `pull_request` de fork. Contribuições externas por PR ficam fechadas.
