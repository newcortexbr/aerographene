aerographene v0.3.4: Linux x86-64-v3 browser, our own patch series on top of ungoogled-chromium with parts of Helium and Brave. This release makes the built-in themes faithful across the whole browser and loads the web store helper only on demand. Notes cover only the range since v0.3.3.

- Chromium 154, CPU target `avx2` (x86-64-v3); no Linux avx1 asset in this release
- CI: Linux build [run 38856809142](https://github.com/newcortexbr/aerographene/actions/runs/38856809142) on commit `2e3c099` (ThinLTO, PGO on); release workflow [run 38879148073](https://github.com/newcortexbr/aerographene/actions/runs/38879148073)
- performance baseline: [`docs/BASELINE.md`](https://github.com/newcortexbr/aerographene/blob/main/docs/BASELINE.md)

## Install (Linux)

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar -xf avx2-linux--aerographene-v0.3.4.tar.zst   # check the extracted directory with tar -tf
./<extracted-dir>/aerographene
```

On Arch use `avx2-arch--aerographene-v0.3.4.pkg.tar.zst` (`pacman -U`); recipe in `packaging/arch/PKGBUILD`. The namcap result is in `avx2-arch--namcap.txt`. Debian/Ubuntu: `avx2-debian--aerographene-v0.3.4.deb`; Fedora: `avx2-fedora--aerographene-v0.3.4.rpm`.


## Changelog

### Themes
- each built-in theme draws its own active-tab marker (bar, dot, lozenge, inversion); the blue gradient stays in `default` only
- the new tab page follows the colors, radii and fonts of the active theme; the `pixelized` greeting uses Pixelify Sans
- internal pages (settings, history, downloads, extensions, bookmarks) take colors, radius, font and toggles from the active theme
- outside `default`, settings menu icons, buttons and toggles follow the theme palette, and settings cards and pill buttons take the theme radius
- `classical` and `graphite` tab markers get their own room in the tab; mono themes end long tab titles with an ellipsis
- Pixelify Sans, Doto, Selawik and Noto Serif (SIL OFL 1.1) are bundled in the Linux packages; Doto is used only in `graphite` titles

### Extensions
- chromium-web-store no longer keeps a permanent service worker; it loads on demand

### Terminal
- `sudo` works in `aerographene://terminal` (the shell no longer inherits `no_new_privs`)
- the shell gets the Wayland/X11/D-Bus session variables, so clipboard tools (`wl-copy`, `wl-paste`) and image paste in TUI apps work
- OSC 52 copy is supported (write only; programs cannot read the clipboard); Ctrl+Shift+V with an image sends ^V like Ctrl+V

### Google
- ungoogled-chromium domain substitution is off: Google search and other real hosts are no longer rewritten to `*.qjz9zk` and blocked

### Build and packaging
- product version 0.3.4 in the binary and package names
- the theme smoke test opens the pages for real and adds sidebar screenshots

## Known limitations

- no Linux avx1 and no Windows assets in this release
- spaces: "New space" is partial (no step indicator, glyph choice or preview)
