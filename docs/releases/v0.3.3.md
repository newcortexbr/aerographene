aerographene v0.3.3: Linux x86-64-v3 browser (and now a Windows build too, untested), our own patch series on top of ungoogled-chromium with parts of Helium and Brave. Notes cover only the range since v0.3.1.

- Chromium 154, CPU target `avx2` (x86-64-v3); no Linux avx1 asset in this release
- Windows: `avx2-windows--aerographene-v0.3.3.zip` and `avx1-windows--aerographene-v0.3.3.zip`, UNTESTED (see Known limitations)
- CI: Linux build [run 38676659389](https://github.com/newcortexbr/aerographene/actions/runs/38676659389) on commit `fc39b55` (ThinLTO, PGO off); release workflow [run 38679676633](https://github.com/newcortexbr/aerographene/actions/runs/38679676633)
- performance baseline: [`docs/BASELINE.md`](https://github.com/newcortexbr/aerographene/blob/main/docs/BASELINE.md). Quick bench (Comet Lake, `--quick`, 10 tabs, n=6): first_ms 772.1, all_ms 848.0, PSS 687.5 MiB, 20 processes
- the `-O3` "wide" profile was tested and rejected (all_ms +2.31% in the quick bench); it is not in this build

## Install (Linux)

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar -xf avx2-linux--aerographene-v0.3.3.tar.zst   # check the extracted directory with tar -tf
./<extracted-dir>/aerographene
```

On Arch use `avx2-arch--aerographene-v0.3.3.pkg.tar.zst` (`pacman -U`); recipe in `packaging/arch/PKGBUILD`. The namcap result is in `avx2-arch--namcap.txt`.

## Install (Windows, untested)

Extract the zip and run `aerographene/aerographene.exe`; the `fonts` folder sits next to the executable. The installer also carries `fonts\`.

## Changelog

### Themes
- eight built-in themes: `default`, `pixelized` and six new ones, `metro-v2`, `e-ink-gb`, `graphite`, `classical`, `e-ink` and `cli`, all as compiled `ThemeData` (dark only). No fonts are bundled: Pixelify Sans and Doto fall back to a system font
- the eight names are reserved when importing a theme
- switch in `chrome://settings/appearance` (applies after restart)

### First use
- `aerographene://setup` opens once per new space: theme, search engine, default browser, notes folder, privacy and import; everything optional

### Tabs and spaces
- Ctrl+Tab switcher in most-recently-used order, with thumbnails Chromium already keeps
- avatar menu, space picker and "New space" screen in the aerographene mono look; "profile" becomes "space" in the texts

### Settings
- `chrome://settings` in the One UI look, appearance only

### Notes and shortcuts
- Ctrl+N in the notes tab creates a note; in other tabs it still opens a new window

### Build and packaging
- product version 0.3.3
- Helium extras out of scope removed (services, MRU, extra shortcuts, window menu, crash reporting)
- `build/win/build.sh` produces the Windows avx2 and avx1 zips; the Windows installer now ships `fonts\`

## Known limitations

- Windows (avx2 and avx1): UNTESTED. Cross-compiled on the Cezanne runner and packaged, never run on Windows. Notes are read-only, the ConPTY terminal never ran, the private JetBrains Mono font is unverified. No PGO
- no Linux avx1 in this release
- spaces: "New space" is partial (no step indicator, glyph choice or preview)
- onboarding, tab switcher, spaces and One UI settings compiled in the green build, without full visual check in the browser
- built-in themes beyond `default` and `pixelized`: compiled, not checked visually; no bundled fonts
- Ctrl+N in notes was not tested in the browser
